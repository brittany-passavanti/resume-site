Build Sequence — 4 Sprints

Create all custom contact and company properties in HubSpot.
Define property groups: "CS Health Score" at company level.
Set up calculated properties for composite score (weighted sum).
Map which data flows automatically vs. CSM manual input.
Build HubSpot workflows to ingest product usage data (WAU, first logins).
Connect AI Academy LMS data feed → HubSpot (course + cert completions).
Set enrollment triggers for new accounts.
Test with 3 pilot accounts.
Activate calculated health score property.
Build 3 HubSpot active lists: Healthy (70+), Needs Attention (45–69), Action Recommended (<45).
Create saved views in CRM for each segment.
Build dashboard in HubSpot Reporting for leadership visibility.
Build workflow: score drops below 45 → auto-task to assigned CSM + Slack notification.
Build workflow: score drops below 30 → escalation to CS lead.
Build workflow: healthy account + renewal in 60 days → trigger expansion playbook.
QBR template auto-populated from health score properties.

Why This Matters — From the CS Blueprint

This build directly maps to the AI for Customer Success Blueprint's core framework: moving from reactive to proactive CS. The health score shifts the team from scheduled check-ins to signal-driven engagement, with AI monitoring behavior and surfacing warning signs before churn becomes inevitable. It also sets up the "natural language analytics" layer because leadership can query account health conversationally once the underlying data is structured in HubSpot. The goal isn't a dashboard. It's a system that tells you which 3 accounts need your attention today — and has already started the process of reaching them.
